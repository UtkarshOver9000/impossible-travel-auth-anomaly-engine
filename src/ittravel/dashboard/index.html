Developer Integration Guide & Tutorials

Step-by-step setup instructions to integrate VigilGuard ITDR into your authentication gateway

1 Generate API Key
2 Instrument Login Handler
3 Enforce Step-Up Auth
4 Production Checklist

Step 1: Obtain a Tenant API Key

Every request to VigilGuard ITDR requires an active API key passed in the X-API-Key HTTP header.

💡 Default Demo Key: Your environment is pre-configured with demo-master-key-9000. You can also generate new keys in the API Keys Portal. 
# Test your API key authentication via cURL
curl -X GET "http://localhost:8000/v1/stats" \
     -H "X-API-Key: demo-master-key-9000"

Step 2: Send Auth Payload on Every Login Attempt

In your auth endpoint (e.g. NextAuth, Passport.js, Django, FastAPI), make an async call to /v1/auth/evaluate right after verifying user password/MFA.

# Python Integration Example
import requests

def on_user_login(user_id, lat, lon, device_id, ip):
    response = requests.post(
        "http://localhost:8000/v1/auth/evaluate",
        headers={"X-API-Key": "demo-master-key-9000"},
        json={
            "user_id": user_id,
            "login_ts": "2026-08-02T15:30:00Z",
            "lat": lat,
            "lon": lon,
            "device_id": device_id,
            "ip": ip
        }
    )
    risk_data = response.json()
    return risk_data

Step 3: Enforce Risk-Based Step-Up Authentication (MFA / Block)

Use the returned risk_score or risk_tier to take automated security actions:

  • 🟢 LOW / MEDIUM (< 60): Allow user login without disruption.
  • 🟡 HIGH (60–79): Require Step-Up Multi-Factor Authentication (WebAuthn / OTP).
  • 🔴 CRITICAL (≥ 80): Immediately block login attempt and dispatch security alert to your SOC.

Step 4: Enterprise Production Checklist

Before launching to production users:

  • ✅ Store API keys in environment variables (e.g. VIGILGUARD_API_KEY).
  • ✅ Implement fallbacks so auth flow fails-open or degrades gracefully if security service is unreachable.
  • ✅ Ensure user IP geolocation lookup uses trusted CDN headers (e.g. CF-IPCountry, X-Forwarded-For).
  • ✅ Deploy to high-availability infrastructure (Vercel Serverless / AWS ECS).
